# Pafuli Studio

A bilingual public website for Pafuli's games and interactive work.

## Project Status

**Stage: Active Development.** The bilingual static site and deployment workflow are present. The next milestone is to verify launch content and connect the custom domain.

## Overview

Pafuli Studio is the public website for the games and interactive practice operated by Studio Pafuli Inc. It provides a simple home for original projects and selected collaborations.

## Current Features

- English and French website content.
- Static Next.js build.
- GitHub Pages deployment on pushes to `main`.
- Public contact by email.
- No contact form and no file-upload flow.
